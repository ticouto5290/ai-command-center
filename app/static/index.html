Recommended models (manual download)

Primary path is Apple MLX on native macOS. Download the MLX or GGUF files below, then add them via the sections further down or place MLX models where the app already discovers them.

PRIMARY · CHAT + NSFW/SFW · MLX

Qwen3.8-27B Uncensored (MLX)

Best all-rounder for this app. Handles normal and uncensored content, tool calling, and long context. Prefer the 4-bit MLX build on Apple Silicon.

Typical size ~15–18 GB · Recommended RAM 32 GB+

Hugging Face · MLX builds ↗ Search related MLX ↗
FAST MOE · MLX / GGUF

Qwen3.6-35B-A3B Abliterated

Mixture-of-Experts (~3B active). Very fast decode on Apple Silicon while keeping strong quality. Good second model when you want speed.

Typical size ~18–22 GB · Recommended RAM 24–32 GB+

Search Abliterated builds ↗ Search MLX ↗
CODING SPECIALIST

Qwen3-Coder / Qwen3.8 Coder family

Use these for coding workspace, app generation, edits, and tool creation. Prefer MLX when available; GGUF also works via llama.cpp.

14B–30B class · 16–32 GB depending on quant

Qwen3-Coder search ↗ Existing 14B MLX ↗
SMALLER / FASTER

Qwen3.5-9B or Gemma-4 12B/26B Heretic

Good when you need lower memory or higher tokens/sec. Uncensored / Heretic / Aggressive variants exist for both SFW and NSFW use.

~6–12 GB · Fits 16–24 GB Macs more comfortably

Training a foundation model from scratch takes far more data and compute than this laptop provides. A practical first version is LoRA or QLoRA fine-tuning: choose a base model, add example conversations or task data, train an adapter, compare its answers, then use the adapter in chat.
